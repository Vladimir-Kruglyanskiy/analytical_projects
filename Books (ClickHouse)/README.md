# Анализ пользовательской активности в сервисе для чтения электронных книг

Анализ пользовательской активности в сервисе Букмейт: исследование поведения пользователей на мобильных платформах и веб-версии, оценка популярности контента, сезонности потребления и технических характеристик приложений.

## Задачи

- Определить топ-20 городов и регионов России по суммарному количеству прочитанных и прослушанных часов
- Выявить топ-5 книг по суммарному количеству прочитанных и прослушанных часов на мобильных платформах
- Определить топ-10 авторов по суммарной длительности чтения их книг на всех платформах
- Проанализировать популярность контента в разрезе платформ
- Исследовать сезонность потребления контента в зависимости от дня недели
- Определить процент пользователей с последней версией приложения в разрезе мобильных ОС
- Выявить частоту обновления приложения в разрезе мобильных ОС
- Подсчитать количество книг с тегом «Магия»
- Найти книги со словом «магия» в названии, для которых не проставлены теги «Магия» и «Художественная литература»
- Рассчитать среднее количество тегов в зависимости от категории
- Найти аномалии в длительности сессии

## Данные

База данных `source_db` содержит 2 таблицы:

| Таблица | Описание |
|---------|----------|
| `audition` | Информация о сессиях чтения/прослушивания (пользователь, платформа, время, версия приложения, геоданные) |
| `content` | Информация о контенте (книги, авторы, тип контента, теги) |

## Инструменты и технологии

- **SQL** (ClickHouse)
- **DBeaver** — среда для работы с базой данных

## Рекомендации

1. **Контентная стратегия** - обратить внимание на успешный опыт биографий известных личностей, но проанализировать причины низкой дочитываемости книги про Маска
2. **Работа с авторами** - усилить сотрудничество с российскими авторами-лидерами (Лисина, Муравьёв), у которых высокая продолжительность прослушивания
3. **Платформенная стратегия** - для iOS сделать упор на текстовый контент (читателей больше на 30%), для Android сохранять паритет между форматами
4. **Техническая оптимизация** - увеличить долю пользователей с актуальными версиями приложений (особенно iOS - всего 20%)
5. **Качество данных** - проверить данные по Латвии на Android, где обнаружена аномалия (коэффициент вариации 7,03)
6. **Тегирование контента** - донастроить теги для 49 книг со словом «магия» в названии, у которых отсутствуют теги «Магия» и «Художественная литература»
